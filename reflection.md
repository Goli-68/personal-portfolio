Q1. New things I learned from AI:
• I learned that I should provide the right information to AI so that it delivers the correct result.
• I learned that I can ask AI to change the colour of elements on Webpage.
• I learned that I can ask AI to make a page or a container responsive for small or big screens.

Q2. Correcting Copilot’s suggestions to suit my needs:
• I used Copilot to make some changes to my code (e.g., Responsive design or CSS centring), and it did it right the first time. So, I didn’t need to correct it or give it new prompts.

Q3. Copilot as a learning partner or to generate code:
• When using copilot to generate codes, it helped me to find quick solutions to my problems. But it also worked as an effective learning partner, because when it provided the right codes, it helped me to learn about the solutions to my problems. So next time, when I have similar issues, I can fix them myself.

Q4. 3 risks of relying too much on AI tools
• If we use AI too much, our mind doesn’t struggle with a problem, so it thinks writing code is not difficult and there’s no need to spend time for learning or discovering new knowledge.
• When we get used to using too much AI, in situations where we don’t have access to AI, we won’t have the necessary skills to solve the tasks ourselves.
• We might lose our creativity and talent of writing code.
